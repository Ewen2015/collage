What is collage art?From the French coller — “to glue”

Collage is an artwork assembled on a flat surface from materials that already exist: newspaper, photographs, printed paper, fabric, tickets, typography. Unlike a painting built from scratch, it works by cutting, rearranging and gluing fragments until unlike things form a new argument.

It began as an experiment in Picasso and Braque's Cubism around 1912, then became photomontage in Dada, impossible spaces in Surrealism, mass-media repetition in Pop, and torn posters in Décollage. It is a technique and a medium rather than one formal movement — its constant is fracture, reassembly and fusion.

The idea comes first, then the scissors.

Most image tools take a style word and return a texture. This skill reads what you wrote, names the tension inside it, and builds an argument out of two unlike things.

A phrase like “the tide keeps coming back, the city pretends to be asleep” becomes a pairing sentence, then three photographable motifs — a breaking wave, a night skyline, a lunar crater — then an arch, a horizon, a headline cut from a magazine. The result is a poster that means something, not a photograph with a collage filter.

So the renderer works in paper stocks, print screens, torn edges, tape and registration marks — and it keeps the ink count to two or three.

  • ReadExtract the tension, write one pairing sentence, choose 2–4 motifs.
  • FindSearch Wikimedia Commons, keep CC / public-domain images, write a credit manifest.
  • ChoosePick a strategy: Cubism, Dada, Surrealism, Pop, Décollage, or editorial.
  • CutCompile a recipe of layers, edges, rotations, type and tape.
  • PasteRender deterministic paper, halftone, shadows, grain. Look at it. Fix it.
  • ExplainDeliver the PNG with the rationale and the image credits.

Install the whole skill.

A skill is a folder, not a prompt: SKILL.md, five references, four scripts, the dependency file and installers. These standard sources install that complete bundle into the skills directory of Claude Code, Codex, Cursor, OpenCode and other skills-compatible agents.

npx skills add Ewen2015/ewen-collage --skill collage-art -g -y

https://github.com/Ewen2015/ewen-collage/raw/main/dist/collage-art.skill

The install carries the whole folder: the SKILL.md workflow, five reference documents, four scripts, requirements.txt, install.sh, install.ps1 and an assets/ folder. A lone SKILL.md is not an install. After installing, run bash install.sh (or install.ps1 on Windows) once from the installed folder — it installs Pillow and NumPy and runs check_setup.py to verify every bundled file, the fonts and the renderer. To test it: python3 scripts/collage.py --preset cubist-grid --out cubist.png. The 16 preset styles work offline; only Wikimedia Commons sourcing needs a connection. Drop -g from the CLI command to install into the current project instead of globally. Full manual path in the README.

Nineteen works.

Sixteen built-in studies of a single strategy, and three made from a theme through the full pipeline. Every one is a real PNG produced by the renderer, not a mock-up.
