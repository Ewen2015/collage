# Theme-driven gallery pieces

`night-train.png` and `garden-of-static.png` in `../gallery/` were produced by
the full pipeline from `concept.json` files in this folder, using
`theme_to_recipe.py` and `collage.py`.

Their `assets/SOURCES.json` manifests deliberately reuse the three Wikimedia
Commons photographs already downloaded and credited in
`examples/demo/assets/SOURCES.json` — they are offline demonstrations of the
composition step, not fresh image searches. See that manifest for the original
authors and licences (CC BY 2.5, CC0, public domain). Do not treat these as
newly sourced works.
